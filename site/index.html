x-section: keys

Switch in a keystroke.

AltShiftH opens Lanehead, 1–9 moves the tab to another backend, R reloads. The toolbar badge shows each tab's lane in its colour.

x-section: lanes

Change a lane once, every tab follows.

A lane is a backend you test against, saved with a name. Edit it in the popup and every tab in that lane picks it up on the next request.

x-section: defaults

Isolated by default

A new tab goes where it always did. Only the tabs you put in a lane go elsewhere, so the rest of your browsing is untouched.

Opened tabs follow

Links, ⌘-clicks and pop-ups from a tab in a lane open in the same lane. You can turn that off.

Stays on your machine

No account, no telemetry, no network requests. Chrome's own request rules do the work; nothing reads your traffic.

x-section: install

Install in a minute.

Lanehead isn't on the Chrome Web Store. You load it from GitHub.

  1. 01

    Download

    Get lanehead-chrome.zip from the latest release and unzip it somewhere it can stay.

  2. 02

    Load unpacked

    Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.

  3. 03

    Pin it

    Pin Lanehead to the toolbar, open it on any tab, and create your first lane.
